# AntNest

> **Exploring scalable multi-agent organization and autonomous collaboration.**
> 探索可扩展的多 Agent 组织形态与自主协作。

AntNest is an independent research and engineering initiative focused on how autonomous AI agents coordinate, divide complex work, and verify outcomes as structured organizations.

## Focus Areas

- **Organization Protocol** — Lightweight, runtime-agnostic specifications for multi-agent structure and collaboration.
- **Experimental Lab** — Isolated environments and visual observability tools for running and inspecting multi-agent systems.

## Status

Core repositories are currently in private preparation and will be open-sourced when ready.
核心仓库正在整理中，准备就绪后将陆续开源。
